# Functions

함수 선언부터 화살표 함수, 나머지 매개변수, 재귀, 콜백, 클로저와 `this`까지 정리합니다.

## Topics

| File | Topics |
|---|---|
| `functionBasic.js` | 함수 선언, 매개변수, 기본값, 반환값 |
| `functionExpression.js` | 함수 표현식 |
| `arrowFunction.js` | 화살표 함수와 반환 방식 |
| `restParameters.js` | 나머지 매개변수와 전개 구문 |
| `recursion.js` | 재귀 호출과 종료 조건 |
| `callback.js` | 콜백 함수 |
| `closure.js` | 클로저와 지역 변수 유지 |
| `thisBinding.js` | `this`, `call`, `apply`, `bind`, 화살표 함수의 `this` |

## Run examples

저장소 최상위 폴더에서 실행합니다. 예를 들어:

```bash
node functions/functionBasic.js
```

각 JavaScript 파일은 독립적으로 실행할 수 있습니다.
